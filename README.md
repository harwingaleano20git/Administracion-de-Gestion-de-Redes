# Administración y Gestión de Redes

Proyecto individual de Harwin Galeano Beltran, Ingeniería de Telecomunicaciones, UCompensar.

Versión actual: **v0.2.1**. [Aplicación e instalación](NETGUARD-NOC/README.md), [guía de demostración](NETGUARD-NOC/docs/DEMOSTRACION-v0.2.1.md) y [código por requisito del profesor](NETGUARD-NOC/docs/Codigo-para-el-profesor.md).

Incluye reglas de indicios, notificaciones Telegram configurables y consola SSH de consultas restringidas. Doce pruebas automatizadas; pendientes las pruebas externas de recepción Telegram y conexión a un equipo autorizado. No hay autenticación web ni RBAC efectivo.

La release v0.2.0 conserva la entrega original del corte 2. Su PDF y video no demuestran esta ampliación. Los materiales de clase originales se conservan en la raíz. No se publican bases locales, tokens ni contraseñas.
